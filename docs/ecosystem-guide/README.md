# 📚 StayBid — The Complete Ecosystem (ChatGPT Manual Kit)

This folder is a **copy-paste kit** for building a premium visual book — *"StayBid: The Complete Ecosystem"* — using ChatGPT's image generation. Each file is a **self-contained chapter** (repeats the style spec, so no memory loss) with **page-by-page image prompts** and the manual **body text**.

## How to use (30-second version)
1. Open **`00-MASTER-INDEX-AND-GLOBAL-SPEC.md`** → read PART A + copy the **GLOBAL RENDER SPEC** into a fresh ChatGPT (image) chat.
2. Build **Front Matter (pages 1–4)** from the master file.
3. Then open each chapter file **in order**, re-paste its spec, and feed the PAGE prompts one at a time — say **`next`** between each.
4. Assemble all images (named `page-01.png` … `page-96.png`) into one **A4-landscape PDF**.

> Every image = one book page. **A4 landscape · 4K · 300 DPI · premium cozy luxury (cream + champagne gold; Chapter 8 admin = dark).**
